# Preloads

Drop your own audio here to auto-fill a template crate. **Never commit copyrighted
audio** — `*.mp3 / *.wav / *.m4a` under this folder are git-ignored.

```
public/preloads/paisa/nusta-paisa.mp3
public/preloads/paisa/paisa-hai-toh.mp3
public/preloads/paisa/hasan-raheem-paisa.mp3
public/preloads/paisa/de-dana-dan.mp3
public/preloads/paisa/paisa-masanga.mp3
```

Optional sidecar `<same-name>.words.json` (`{"words":[{"w":"paisa","start":12.3,"end":12.8,"p":0.9}]}`)
skips transcription — handy when the analysis service isn't deployed.
